# Lumen Camera
Photo-only pro camera (back lenses only). Camera2 API: manual ISO / shutter / focus / EV / WB, AE+AF lock, flash, timer,
tap-to-focus, pinch zoom, RAW (DNG) and RAW+JPG, full-resolution (48/50/64/108/200 MP) when the phone allows it,
in-camera filters and a flat D-Log curve, crisp high-quality processing, lens switching. Saves to Pictures/LumenCamera.
Build: upload LumenCamera.zip to a GitHub repo (see workflow in .github/workflows/build.yml).
